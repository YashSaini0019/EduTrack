Core Features

Core Features

Everything you need to track and predict placements

Placement Prediction

Random Forest classifier predicts placement probability based on CGPA, backlogs, internships, projects, and academic scores.

Salary Estimation

Gradient Boosting regressor provides expected salary ranges (low/median/high) based on historical data and student profile.

Skill Gap Analysis

Compare student skills against target role requirements and identify missing skills to bridge gaps effectively.

Company Recommendations

Content-based recommender matches student profiles with companies that historically hired similar candidates.

Department Analytics

Comprehensive dashboards showing placement rates, average packages, top companies, and in-demand skills by department.

Student Dashboard

Full student performance table with filtering and sorting to track individual metrics and progress.

Get Started in 5 Minutes

Clone and run locally

1. Clone Repository

git clone https://github.com/YashSaini0019/EduTrack.git
cd EduTrack

2. Install Dependencies & Train Models

cd ml
pip install -r requirements.txt
python train_placement_model.py
python train_salary_model.py

3. Start Backend API

cd ../backend
python app.py
# API runs at http://localhost:5000

4. Start Frontend Dashboard

cd ../frontend
npm install
npm run dev
# Dashboard at http://localhost:5173

5. Access Dashboard

Open http://localhost:5173 in your browser
and start making predictions!

API Endpoints

Flask REST API available at /api/

POST /api/predict/placement

Predict placement probability for a student profile

POST /api/predict/salary

Get expected salary range (low/median/high)

POST /api/skill-gap

Analyze skill gaps for a target role

POST /api/recommend/companies

Get top matching companies for a student

GET /api/analytics/department

Department-wise placement statistics

GET /api/students

List all students with their performance metrics
