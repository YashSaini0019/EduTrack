## 🔧 Customization Guide

### Change Colors
**File**: `/docs/styles.css` (Lines 7-14)

```css
:root {
    --primary: #6366f1;        /* Main color */
    --secondary: #ec4899;      /* Accent color */
    --dark: #1f2937;           /* Dark background */
    --light: #f3f4f6;          /* Light background */
    --text: #374151;           /* Text color */
    --border: #e5e7eb;         /* Border color */
}
```

### Update Text
**File**: `/docs/index.html`

Search for the section you want to edit:
- `<h1>` tags for headings
- `<p>` tags for paragraphs
- `.subtitle` class for subtitles

### Change Images/Icons
**File**: `/docs/index.html`

Find `.feature-icon` sections and change Font Awesome icons:
```html
<i class="fas fa-brain"></i>        <!-- Change this -->
```

Browse available icons: https://fontawesome.com/icons

## 🆘 Troubleshooting

**Website not showing?**
- ✅ Check Settings > Pages is enabled
- ✅ Wait 2-3 minutes for GitHub to build
- ✅ Hard refresh browser (Ctrl+Shift+R)
- ✅ Check branch is set to `gh-pages-setup`

**Styling looks broken?**
- ✅ Verify `styles.css` is in `/docs` folder
- ✅ Clear browser cache
- ✅ Try incognito/private mode

**Links not working?**
- ✅ Scroll to anchor ID matches (e.g., #features)
- ✅ Ensure internal links have correct paths
- ✅ GitHub link should work (external URL)

**Help?**
- 📖 Read `/docs/README.md`
- 📖 Read `/docs/DEPLOYMENT.md`
- 📖 Check main `README.md` in root
- 💬 Open GitHub Issue
